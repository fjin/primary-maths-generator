Command line

CLI Instructions

Use the CLI when you want the LaTeX-generated worksheet PDF, repeatable output from a seed, or batch generation from your terminal.

Start Locally


            git clone https://github.com/fjin/primary-maths-generator.git
            cd /some_path/code_location/
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

Generate a PDF

python3 generate.py --topic number_system --questions 40 --difficulty year5

Files are written to the output folder. If pdflatex is installed, the command writes both .tex and .pdf files.

Useful Examples

python3 generate.py --topic mixed --questions 100 --difficulty year5 --seed 2026
python3 generate.py --topic fractions --questions 40 --difficulty year5 --columns 2
python3 generate.py --topic word_problems --subtopic time --questions 30 --difficulty year5
python3 generate.py --topic number_system --questions 40 --difficulty year5 --no-multiple-choice
python3 generate.py --topic money --questions 50 --no-pdf

Common Options

--topic
Choose a topic, such as number_system, fractions, money, time, word_problems, or mixed.
--subtopic
Filter to a subtopic. You can use comma-separated subtopics for some topics.
--questions
Set how many questions to generate.
--difficulty
Use values such as year3, year4, year5, year6, naplan, or selective.
--seed
Use the same seed to generate the same worksheet again.
--columns
Set question columns. Allowed values are 1, 2, and 3.
--answer-columns
Set answer key columns. Allowed values are 1, 2, 3, and 4.
--no-multiple-choice
Hide multiple-choice options and print only the question stem.
--no-pdf
Write only the LaTeX file and skip PDF compilation.
